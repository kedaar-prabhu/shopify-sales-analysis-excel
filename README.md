# Shopify Sales Analysis 2024 — Excel Project

## Project Overview
End-to-end sales analysis of a Shopify e-commerce store using 
Microsoft Excel. Built as part of my data analytics portfolio 
to demonstrate real-world data analysis skills.

## Dataset
- 1,000 orders from FY 2024
- 23 columns including order details, customer info, 
  payment method, sales channel and fulfillment status
- Realistic Shopify-style synthetic data

## What I Built

### 1. Data Cleaning (Orders_Clean sheet)
- Removed duplicates and handled blank cells
- Added helper columns: Month Name, Quarter, Net Revenue
- Formatted dates and converted to Excel Table

### 2. KPI Summary Sheet
- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Refund Rate and Cancellation Rate
- Best Revenue Month using INDEX MATCH

### 3. Pivot Tables
- Revenue by Month
- Orders by Sales Channel
- Fulfillment Status Breakdown
- Revenue by Product Category
- Payment Method AOV Analysis

### 4. Executive Sales Dashboard
- 4 KPI tiles (Revenue, Orders, AOV, Refund Rate)
- Monthly Revenue Line Chart
- Sales Channel Bar Chart
- Fulfillment Status Donut Chart
- Interactive Slicers for Month and Sales Channel

### 5. Business Insights Report
- 7 data-backed findings
- Executive summary
- Sparkline trend charts
- Supporting formulas for each insight

## Key Findings
- Q4 drove the highest revenue of the year
- Online Store was the strongest sales channel
- 62% of orders used a discount code
- Refunded orders had the highest average order value
- More than half of orders qualified for free shipping

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel Formulas: SUMPRODUCT, COUNTIF, AVERAGEIF, SUMIF, INDEX MATCH
- Conditional Formatting
- Sparklines
